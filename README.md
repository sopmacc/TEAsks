🧩 TEAsks

Este projeto é um aplicativo mobile desenvolvido para auxiliar crianças com Transtorno do Espectro Autista (TEA) na organização de tarefas diárias e na construção de bons hábitos. 
Através de recursos visuais e feedback positivo, buscamos reduzir a ansiedade e promover a autonomia.

🛠️ Tecnologias Utilizadas
Frontend: GODOT ENGINE

Backend: GDScript

Banco de Dados: SQLite

Design: Canva

🎨 Acessibilidade e Design
O projeto foi pensado seguindo diretrizes específicas para o público neurodivergente:

Contraste adequado: Cores pasteis que não agridem a visão.

Iconografia Clara: Ícones que representam ações literais.

Navegação Simplificada: Menos cliques para chegar ao objetivo.
